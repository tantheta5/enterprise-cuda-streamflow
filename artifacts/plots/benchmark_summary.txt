* Key Insight: In the 5x5 convolution filter, each pixel is sampled 25 times. The naive kernel generates
  25 independent global memory read requests per pixel. In contrast, the tiled shared-memory kernel loads
  each halo-apron tile collaboratively, reading each byte from global memory only ~1.56 times (20x20 tile /
  16x16 output), achieving a 3.85x speedup and saving over 74% of off-chip global memory bandwidth!
